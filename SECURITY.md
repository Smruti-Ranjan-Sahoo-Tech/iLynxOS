# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.03+   | :white_check_mark: |
| < 1.03  | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within iLynxOS (such as sandbox escapes, unauthorized host access outside PRoot boundaries, or display server memory corruption), please do **NOT** open a public issue on GitHub.

Instead, please send an email with the details to:
- **Maintainer:** Smruti Ranjan Sahoo
- **Email:** [s.r.sahoo370@gmail.com](mailto:s.r.sahoo370@gmail.com)

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact on the user device or environment.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
